# ETAPA 01: AUDIO
Lee DIRECCION.md (secciones 7 y 10). Crea tools/gen_audio.py:
1. Con edge-tts (es-MX-JorgeNeural, rate +8%, boundary="WordBoundary") genera public/audio/vo/s01.mp3...s06.mp3 con las líneas VOZ de la sección 10 y guarda el tiempo de cada palabra. Si no hay tiempos por palabra, repártelos proporcionalmente.
2. Si una voz dura más de (frames/30 - VO_DELAY/30 - 0.3) s, regenera con rate más alto (hasta +25%); si aún no cabe, imprime advertencia con la escena.
3. Escribe src/explained/timings.ts (autogenerado): export const VO_TIMINGS: {scene:number; file:string; durationSec:number; words:{text:string; startSec:number; endSec:number}[]}[].
4. Con numpy + wave (44.1 kHz estéreo, pico máx 0.8) sintetiza public/audio/music.wav (34 s, 108 BPM: bajo sierra con arpegio, pad, kick, snare, hi-hat, intro de 2 compases y breakdown casi silencioso entre los segundos 22.3 y 23.6) y los SFX: whoosh, hit, riser (2 s), glitch, pop, sting.
Al terminar: /run pip install edge-tts numpy && python tools/gen_audio.py
